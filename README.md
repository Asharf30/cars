# CarHub 🚗

A car catalogue web app for browsing, filtering, and exploring vehicles — built as a personal portfolio project.

**🔗 Live Demo:** [asharf-cars.vercel.app](https://asharf-cars.vercel.app/)

## Built With

- [Next.js] (App Router) + TypeScript
- [Tailwind CSS v4]
- [Headless UI]
- [Framer Motion]
- [FuelEconomy.gov API] — vehicle data
- [CarImages API] — vehicle images

## Features

- 🔍 Browse cars by year, manufacturer, and model
- ⚡ Filter by fuel type, including electric vehicles
- 🛒 Shopping cart with quantity control and persistent storage
- 🎨 Smooth animations and a responsive, modern UI
